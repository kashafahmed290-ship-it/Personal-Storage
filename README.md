# ☁️ Personal Cloud Vault

A completely offline, secure, and modern browser-based Cloud Storage application built in a **single HTML file**. No backend servers required—all your files are stored securely in your browser's local database (IndexedDB).

## ✨ Features
- **🔒 Password Protected:** Set a password on your first visit to secure your vault.
- **📁 File & Folder Management:** Create folders, upload files, rename, move, and delete.
- **🚀 Drag & Drop:** Easily drag and drop files from your computer to upload.
- **👁️ Live Preview:** View Images, PDFs, Videos, Audio, and Text files directly inside the app.
- **🌗 Dark/Light Mode:** Toggle between a sleek pure dark mode and a clean light mode.
- **💾 100% Offline:** Uses IndexedDB to store files entirely on your local machine.
- **📱 Responsive:** Works beautifully on desktops, tablets, and mobile phones.
- **⌨️ Shortcuts:** Support for `Ctrl+A` (Select All) and `Delete` keys.

## 🛠️ How to Use
Since this project uses no external databases or servers, running it is incredibly easy:
1. Clone this repository or download the `index.html` file.
2. Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).
3. Set a password on your first launch.
4. Start uploading your files!

## ⚠️ Important Note on Storage
Because this app relies on the browser's IndexedDB:
* Clearing your browser's cache/site data **will delete your stored files**.
* Files are only accessible on the specific device and browser where you uploaded them.
* Do not use this as your *only* backup for critical files.
